# HOTI - Helping Others Through creativity & Innovation

A modern, responsive website for HOTI, an organization dedicated to empowering youth ages 12-17 through innovative programs and creative opportunities.

## 🌟 Website Features

- **Hero Section**: Compelling tagline with clear call-to-action buttons
- **Core Values**: Showcase of organizational values (Compassion, Creativity, Community, Excellence)
- **About Section**: Mission, vision, target audience, and approach with statistics
- **Programs**: 7 detailed program offerings with enrollment information
- **Blog & Resources**: Educational content and helpful resources for youth
- **FAQ**: Interactive accordion with common questions and answers
- **Contact**: Comprehensive contact form and organizational information
- **Responsive Design**: Mobile-first approach with tablet and desktop optimization

## 🚀 Live Website

The website is deployed on GitHub Pages: [https://kosi-ugorji.github.io/hoti/](https://kosi-ugorji.github.io/hoti/)

## 📱 Programs Offered

4. **Music Production** (14 weeks, 8 spots) - Create and produce original music

## 🔧 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/kosi-ugorji/hoti.git
   cd hoti
   ```

2. Start a local server:
   ```bash
   python3 -m http.server 8000
   ```

3. Open your browser to `http://localhost:8000`

## 📝 Content Updates

### Adding New Programs
Edit `index.html` and add program cards in the Programs section following the existing structure.

### Updating Contact Information
Modify the contact details in the Contact section of `index.html`.

### Adding FAQ Items
Add new questions and answers in the FAQ section with the appropriate HTML structure.

### Blog Posts
Add new blog cards in the Blog & Resources section.
